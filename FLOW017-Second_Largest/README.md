<h2><a href="https://www.codechef.com/practice/course/logical-problems/DIFF800/problems/FLOW017?tab=statement">Second Largest</a></h2><h4>Difficulty: N/A</h4><div class="_problemStatementWrapper_bh3c4_33"><div class="_problemBodyContent_bh3c4_71"><h3 class="notranslate">Second Largest</h3><p>
	Three numbers <b>A</b>, <b>B</b> and <b>C</b> are the inputs. Write a program to find second largest among them.
</p>
<div class="notranslate">
<h3>Input Format</h3>
<p>The first line contains an integer <b>T</b>, the total number of testcases. Then <b>T</b> lines follow, each line contains three integers <b>A</b>, <b>B</b> and <b>C</b>.</p>
</div><div class="notranslate">
<h3>Output Format</h3>
<p>For each test case, display the second largest among <b>A</b>, <b>B</b> and <b>C</b>, in a new line.</p>
</div>
<h3 class="notranslate">Constraints</h3>
<div class="_html_code__block_bh3c4_219 notranslate">
<ul><li>1 <b>≤</b> <b>T</b> <b>≤</b> 1000</li>
<li>1 <b>≤</b> <b>A,B,C</b> <b>≤</b> 1000000</li>
</ul>
</div>
