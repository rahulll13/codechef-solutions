<h3 class="notranslate">Explanation:</h3>
<div class="notranslate">
<p><strong>Test case 1: 2 12 10</strong></p>
<ul>
<li>X = 2 (2 levels remain)</li>
<li>Y = 12 (each level takes 12 minutes)</li>
<li>Z = 10 (Chef would take a 10-minute break every 3 levels, but since there are only 2 levels, no break is needed)</li>
</ul>
<p>Since there are only 2 levels, and no break is needed (because Chef takes a break only after every 3 levels).</p>
<p>The total time = X × Y = 2 × 12 = 24&nbsp;minutes.</p>
<p><strong>Test case 3: 7 20 8</strong></p>
<ul>
<li>X = 7 (7 levels remain)</li>
<li>Y = 20 (each level takes 20 minutes)</li>
<li>Z = 8  (Chef takes an 8-minute break after every 3 levels)</li>
</ul>
<p>Now, let's break this down: <br>
Chef completes the first 3 levels: 3 x 20 = 60 minutes.<br>
After completing these 3 levels, Chef takes an 8-minute break.<br>
Chef completes another 3 levels: 3 x 20 = 60 minutes. <br>
After completing these 3 levels, Chef takes another 8-minute break.<br>
Now, Chef completes the remaining 1 level: 1 x 20 = 20 minutes.</p>
<p>So, the total time = 60 + 8 + 60 + 8 + 20 = 156  minutes.</p>
