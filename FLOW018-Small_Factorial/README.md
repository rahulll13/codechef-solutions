<h2><a href="https://www.codechef.com/practice/course/logical-problems/DIFF800/problems/FLOW018?tab=statement">Small Factorial</a></h2><h4>Difficulty: N/A</h4><div class="_problemStatementWrapper_bh3c4_33"><div class="_problemBodyContent_bh3c4_71"><h3 class="notranslate">Small Factorial</h3><p>
Write a program to find the factorial value of any number entered by the user.
</p>
<div class="notranslate">
<h3>Input Format</h3>
<p> 
The first line contains an integer <b>T</b>, the total number of testcases. Then <b>T</b> lines follow, each line contains an integer <b>N</b>. 
</p>
</div><div class="notranslate">
<h3>Output Format</h3>
<p>For each test case, display the factorial of the given number <b>N</b> in a new line.</p>
</div>
<h3 class="notranslate">Constraints</h3>
<div class="_html_code__block_bh3c4_219 notranslate">
<ul>
<li>1 <b>≤</b> <b>T</b> <b>≤</b> 1000</li>
<li>0 <b>≤</b> <b>N</b> <b>≤</b> 20</li>
</ul>
</div>
